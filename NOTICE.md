# Third-party components

This portfolio contains code written by Johannes Robert Chariton, plus the following
third-party dependencies, which are not vendored in this repository but installed by the
package managers listed below.

## ocr-invoices (Python)

| Component | License | Used for |
|---|---|---|
| pytesseract | Apache-2.0 | Python wrapper around Tesseract |
| Tesseract OCR | Apache-2.0 | OCR engine (installed separately, not shipped) |
| tesseract `deu`/`eng` traineddata | Apache-2.0 | language data |
| Pillow | MIT-CMU | image handling |
| pypdfium2 / PDFium | Apache-2.0 / BSD-3-Clause | PDF rendering |
| FastAPI | MIT | web API |
| Uvicorn | BSD-3-Clause | ASGI server |
| python-multipart | Apache-2.0 | file upload parsing |
| pytest | MIT | tests |

## e2e-tests (Python)

| Component | License | Used for |
|---|---|---|
| pytest-playwright | Apache-2.0 | test fixtures |
| Playwright | Apache-2.0 | browser automation |
| Chromium (Playwright build) | BSD-3-Clause and others | test browser |
| requests | Apache-2.0 | API calls in tests |

## sportsbet-scanner (Python/JavaScript)

| Component | License | Used for |
|---|---|---|
| FastAPI, Uvicorn, Pydantic | MIT / BSD / MIT | backend |
| Python standard library (sqlite3, json) | PSF-2.0 | storage, parsing |

The dashboard uses no external JavaScript library.

## Notes

- No third-party source code is copied into this repository.
- Binary dependencies (Tesseract, Chromium) are downloaded locally and are not redistributed.
- The demo invoices in `ocr-invoices/sample/` are generated by `tools/make_samples.py`;
  company names, addresses, IBAN and VAT IDs are invented.
- `Reportofon` (a separate, private repository) is **not** part of this portfolio and is
  not covered by this notice. It vendors third-party decoder code with its own licenses
  (including GPL-2.0 components), which is why its source is kept private.
